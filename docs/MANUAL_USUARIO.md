## Primeiros Passos

Acesse o sistema pelo navegador no endereço fornecido pelo responsável técnico do clube. Não é necessário instalar nenhum programa.

> Navegadores recomendados: Google Chrome, Microsoft Edge ou Mozilla Firefox (versões atualizadas).

---

## Navegação

O sistema possui um **menu lateral** fixo à esquerda com os seguintes itens:

| Item do menu | O que faz |
|---|---|
| **Dashboard** | Visão geral com indicadores do clube |
| **Desbravadores** | Lista e cadastro de membros |
| **Unidades** | Gerenciar os grupos internos |
| **Classes** | Visualizar as classes de progressão |
| **Especialidades** | Cadastro de especialidades disponíveis |
| **Mensalidades** | Grade de pagamentos mensais |
| **Caixa** | Entradas e saídas financeiras |
| **Custos** | Despesas operacionais |
| **Patrimônio** | Inventário de bens do clube |
| **Atas** | Registro de reuniões |
| **Atos** | Documentos administrativos |
| **Relatórios** | Geração de documentos para impressão |

Clique em qualquer item do menu para navegar até a tela correspondente.

## Dashboard

**Como acessar:** clique em **Dashboard** no menu lateral.

A tela inicial exibe um resumo da situação atual do clube:

### Indicadores (cards superiores)

| Indicador | O que mostra |
|---|---|
| **Desbravadores Ativos** | Total de membros com status "Ativo" |
| **Inadimplentes (mês atual)** | Quantos membros ainda não pagaram o mês corrente |
| **Saldo de Caixa** | Saldo total (entradas menos saídas registradas) |
| **Patrimônio Total** | Soma dos valores de aquisição de todos os bens |

> Um saldo negativo aparece em vermelho; positivo, em verde.

### Gráficos

- **Mensalidades por Mês** — barras verdes (pagos) e cinzas (pendentes) para cada mês do ano. Permite visualizar rapidamente em quais meses a arrecadação foi melhor ou pior.
- **Distribuição por Unidade** — gráfico de pizza mostrando a proporção de desbravadores ativos em cada unidade.

### Últimas Transações de Caixa

Tabela com as movimentações financeiras mais recentes. Entradas aparecem em verde com sinal `+`; saídas em vermelho com sinal `−`.

## Cadastros

### Cadastrar um Novo Desbravador

1. No menu lateral, clique em **Desbravadores**.
2. Clique no botão **Novo Desbravador** (canto superior direito).
3. Preencha o formulário:

   | Campo | Dica |
   |---|---|
   | **Nome completo** | Obrigatório. Use o nome completo conforme o documento. |
   | **CPF** | Formato: `000.000.000-00` |
   | **Data de nascimento** | Selecione no calendário. |
   | **Sexo** | Masculino ou Feminino. |
   | **Cargo** | Desbravador, Conselheiro, Instrutor, Aspirante ou Diretor. |
   | **Status** | Use "Ativo" para membros regulares. |
   | **Unidade** | Selecione a unidade à qual o membro pertence. |
   | **Classe atual** | Selecione a classe de progressão atual. |
   | **Responsável** | Nome e telefone do responsável (para menores de idade). |

4. Clique em **Salvar**.

---

### Editar ou Visualizar um Desbravador

1. Vá até **Desbravadores**.
2. Localize o desbravador na lista (use a busca por nome ou os filtros de unidade e status).
3. Clique no ícone de olho (👁) na coluna **Ações** para abrir a ficha completa.
4. Na ficha, clique em **Editar** para alterar os dados.
5. Após as alterações, clique em **Salvar**.

Para **excluir** um desbravador, abra a ficha e clique em **Excluir**. Uma confirmação será solicitada antes da exclusão.

> **Atenção:** a exclusão é permanente. Se o membro se afastou temporariamente, prefira alterar o status para "Inativo" em vez de excluí-lo.

---

### Especialidades do Desbravador

Na ficha individual de um desbravador é possível registrar as especialidades conquistadas:

1. Abra a ficha do desbravador (ícone 👁).
2. Role até a seção **Especialidades**.
3. Clique em **Adicionar Especialidade**.
4. Selecione a especialidade na lista e informe:
   - **Status:** `Em andamento` ou `Concluída`
   - **Data de conclusão** (se já concluída)
5. Clique em **Salvar**.

### Unidades

**Como acessar:** clique em **Unidades** no menu.

Unidades são os grupos internos do clube (ex.: Águias, Falcões, Leões).

**Cadastrar nova unidade:**
1. Clique em **Nova Unidade**.
2. Informe o nome da unidade e, opcionalmente, o nome e contato do líder.
3. Clique em **Salvar**.

---

### Classes

**Como acessar:** clique em **Classes** no menu.

As 6 classes de progressão (Amigo, Companheiro, Pesquisador, Pioneiro, Excursionista, Guia) já vêm pré-cadastradas no sistema. Não é necessário cadastrá-las manualmente.

---

### Especialidades

**Como acessar:** clique em **Especialidades** no menu.

Exibe a lista de especialidades disponíveis para conquista pelos desbravadores.

**Cadastrar nova especialidade:**
1. Clique em **Nova Especialidade**.
2. Preencha: nome, área (ex.: Artes, Saúde, Ciências), nível (1 a 3) e descrição opcional.
3. Clique em **Salvar**.

## Mensalidades

**Como acessar:** clique em **Mensalidades** no menu.

### Entendendo a Grade

A tela exibe uma tabela com:
- **Linhas:** desbravadores ativos
- **Colunas:** meses do ano (Jan a Dez)
- **Células:** status de pagamento de cada desbravador em cada mês

Cada célula exibe um indicador colorido:

| Símbolo | Cor | Significado |
|---|---|---|
| ✓ | Verde | Mensalidade paga |
| — | Cinza | Pendente (ainda não paga) |
| ! | Vermelho | Atrasada (prazo vencido) |
| I | Azul | Isento |

No cabeçalho de cada coluna aparece o placar do mês, por exemplo: `4/8` significa que 4 de 8 desbravadores já pagaram.

### Registrar um Pagamento

1. Localize o desbravador na linha correspondente.
2. Clique na célula do mês desejado.
3. O status alternará automaticamente entre **Pendente** e **Pago**.
4. A data de pagamento é registrada automaticamente como a data atual.

> Para marcar como "Atrasado" ou "Isento", será necessário editar o registro diretamente.

### Filtros e Navegação de Ano

- Use o **filtro de unidade** (no topo) para exibir apenas os desbravadores de uma unidade específica.
- Use as setas **‹** e **›** ao lado do ano para navegar entre anos diferentes.

### Total Arrecadado

Abaixo do título da página é exibido o valor total arrecadado em mensalidades no ano selecionado.

## Caixa

**Como acessar:** clique em **Caixa** no menu.

Registra todas as entradas e saídas financeiras do clube.

### Cards de Resumo

| Card | Descrição |
|---|---|
| **Entradas** | Soma de todos os valores recebidos |
| **Saídas** | Soma de todos os valores pagos |
| **Saldo** | Entradas menos Saídas |

### Registrar um Novo Lançamento

1. Clique em **Novo Lançamento** (canto superior direito).
2. Preencha o formulário:

   | Campo | Dica |
   |---|---|
   | **Tipo** | "Entrada" para valores recebidos; "Saída" para valores pagos. |
   | **Descrição** | Descreva o lançamento (ex.: "Arrecadação evento junino"). |
   | **Valor (R$)** | Informe o valor numérico (ex.: 150,00). |
   | **Data** | Data em que a movimentação ocorreu. |
   | **Categoria** | Mensalidade, Evento, Doação, Material ou Outro. |
   | **Referência** | Campo opcional para identificar o evento ou pessoa relacionada. |

3. Clique em **Lançar**.

### Excluir um Lançamento

Clique em **Excluir** na linha do lançamento desejado. Uma confirmação será solicitada.

> Exclusões no caixa não podem ser desfeitas. Verifique antes de confirmar.

### Filtrar por Tipo

Use o filtro no topo da lista para exibir apenas Entradas, apenas Saídas ou todos os lançamentos.

## Custos

**Como acessar:** clique em **Custos** no menu.

Registra as despesas operacionais do clube (separado do caixa para melhor organização interna).

### Registrar um Novo Custo

1. Clique em **Novo Custo**.
2. Preencha:

   | Campo | Dica |
   |---|---|
   | **Descrição** | Nome ou descrição da despesa. |
   | **Valor (R$)** | Valor total da despesa. |
   | **Data** | Data de vencimento ou realização. |
   | **Categoria** | Material, Evento, Manutenção, Alimentação, Transporte ou Outro. |
   | **Fornecedor** | Nome da empresa ou pessoa que forneceu o produto/serviço. |
   | **Nota Fiscal** | Número da NF, se houver. |
   | **Status** | "Pendente" se ainda não foi pago; "Pago" se já foi quitado. |

3. Clique em **Salvar**.

### Resumo Financeiro

O topo da página exibe:
- **Pendente:** total das despesas ainda não pagas
- **Pago:** total das despesas já quitadas

## Patrimônio

**Como acessar:** clique em **Patrimônio** no menu.

Inventário de todos os bens pertencentes ao clube (equipamentos, móveis, instrumentos, etc.).

### Registrar um Novo Bem

1. Clique em **Novo Item**.
2. Preencha:

   | Campo | Dica |
   |---|---|
   | **Nome do bem** | Ex.: "Barraca de camping", "Caixa de som". |
   | **Nº de Tombamento** | Código identificador único do bem (etiqueta patrimonial). |
   | **Valor de aquisição** | Valor pago na compra. |
   | **Data de aquisição** | Data da compra. |
   | **Estado de conservação** | Ótimo, Bom, Regular, Ruim ou Baixado. |
   | **Localização** | Onde o bem está guardado. |

3. Clique em **Salvar**.

### Estados de Conservação

| Estado | Quando usar |
|---|---|
| **Ótimo** | Bem em perfeito estado de uso |
| **Bom** | Pequenos sinais de uso, sem comprometimento |
| **Regular** | Uso funcional com desgaste visível |
| **Ruim** | Necessita reparo para uso seguro |
| **Baixado** | Descartado, vendido ou inservível |

> Bens com estado "Baixado" são excluídos do cálculo do Patrimônio Total no Dashboard.

## Atas

**Como acessar:** clique em **Atas** no menu.

Registro formal das reuniões do clube.

### Criar uma Nova Ata

1. Clique em **Nova Ata**.
2. Preencha:

   | Campo | Dica |
   |---|---|
   | **Número** | Número sequencial da ata (ex.: 1, 2, 3...). |
   | **Data** | Data em que a reunião ocorreu. |
   | **Tipo** | Diretoria, Clube, Pais ou Extraordinária. |
   | **Local** | Local onde a reunião foi realizada (ex.: "Sede do clube"). |
   | **Pauta** | Assuntos tratados na reunião. |
   | **Conteúdo** | Texto completo da ata. |
   | **Aprovada** | Marque quando a ata for aprovada na reunião seguinte. |
   | **Data de aprovação** | Data em que a ata foi formalmente aprovada. |

3. Clique em **Salvar**.

### Visualizar ou Editar uma Ata

Na lista de atas, clique no ícone de olho (👁) na coluna de ações para abrir a ata completa. A partir daí é possível editar o conteúdo ou alterar o status de aprovação.

### Tipos de Reunião

| Tipo | Quando usar |
|---|---|
| **Diretoria** | Reuniões da diretoria do clube |
| **Clube** | Reuniões gerais com todos os membros |
| **Pais** | Reuniões com pais e responsáveis |
| **Extraordinária** | Reuniões convocadas em caráter urgente/especial |

**Como acessar:** clique em **Atos** no menu.

Documentos administrativos formais emitidos pela direção do clube.

### Criar um Novo Ato

1. Clique em **Novo Ato**.
2. Preencha:

   | Campo | Dica |
   |---|---|
   | **Número** | Número sequencial do documento. |
   | **Data** | Data de emissão do documento. |

| Tipo | Quando usar |
|---|---|

## Relatórios

**Como acessar:** clique em **Relatórios** no menu.

Exibe cards com os relatórios disponíveis. Clique em qualquer card para abrir o relatório e imprimi-lo.

### Relatórios Disponíveis

| Relatório | Quando usar |
|---|---|
| **Autorização de Saída** | Formulário para os responsáveis assinarem autorizando a participação do desbravador em eventos externos (acampamentos, excursões, etc.). |
| **Fluxo de Caixa** | Extrato financeiro com entradas, saídas e saldo por período. Útil para prestação de contas. |
| **Patrimônio** | Lista completa do inventário de bens com valores e estado de conservação. |
| **Livro Ata e Atos** | Compilado de todas as atas e atos em formato de livro, pronto para impressão e arquivamento. |
| **Mensalidades** | Boletim de pagamentos por mês, mostrando o status de cada desbravador. |
| **Cadastros** | Listagem completa de desbravadores com dados de contato, unidade e classe. |

### Como Imprimir

1. Clique no card do relatório desejado.
2. O relatório será exibido na tela.
3. Use o atalho **Ctrl + P** (Windows/Linux) ou **Cmd + P** (Mac) para abrir o diálogo de impressão.
4. Selecione a impressora ou a opção **"Salvar como PDF"** para salvar o arquivo.

## Perguntas Frequentes

**Como faço para marcar uma mensalidade como "Atrasada"?**
A marcação de "Atrasado" precisa ser feita manualmente na ficha. Clique na célula da mensalidade e, em seguida, use a opção de edição para alterar o status. O sistema futuramente poderá marcar automaticamente conforme a data de vencimento.

**Posso desfazer uma exclusão?**
Não. Exclusões de desbravadores, transações de caixa, atas e outros registros são permanentes. Caso exclua algo por engano, o registro precisará ser recadastrado manualmente.

**Como alterar o status de um desbravador que se transferiu para outro clube?**
Abra a ficha do desbravador (ícone 👁), clique em **Editar** e altere o campo **Status** para "Transferido". Isso remove o membro da grade de mensalidades ativas sem excluir seu histórico.

**O saldo do caixa no Dashboard não bate com o que eu esperava. Por quê?**
O saldo exibe o total acumulado de todas as transações registradas no módulo **Caixa**. Verifique se há lançamentos duplicados ou se alguma entrada/saída ainda não foi registrada.

**Como fazer backup dos dados?**
Os dados ficam armazenados no Supabase (banco de dados na nuvem). O responsável técnico deve configurar backups automáticos no painel do Supabase. Contate o administrador do sistema para mais informações.

**Posso acessar o sistema pelo celular?**
Sim. O sistema é responsivo e funciona em navegadores de celular (Chrome ou Safari). A visualização é otimizada para telas maiores, mas todas as funcionalidades estão disponíveis em dispositivos móveis.
